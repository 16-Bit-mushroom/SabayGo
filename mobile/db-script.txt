2.3.5	Architecture Design
SabayGo utilizes a structured, multi-tier client–server architecture engineered for secure concurrent transaction handling and event-driven AI auditing. The Client/Frontend Layer is divided into two distinct interfaces: a Flutter cross-platform mobile application (using the MVVM pattern) for Passengers and Drivers, and a Web Application serving as the Operator command center. The mobile client integrates the Google Maps SDK for node-based route visualization and Firebase Authentication for secure access. At the edge layer, an in-van IoT camera captures cabin snapshots triggered by door closures or specific GPS nodes to initiate physical audits.

The Server/Backend Layer is built on Python and FastAPI, utilizing Clean Architecture and Domain-Driven Design (DDD). The backend isolates core business rules from the Infrastructure Layer [21], [22]. To combat revenue leakage, the system integrates an AI Inference Microservice running the YOLOv8 object detection model. This pipeline processes incoming camera frames to count physical passengers, returning a visual headcount (Cvisual) and a privacy-compliant blurred snapshot to the core backend for discrepancy calculation against the digital manifest (Cbooked).
To support persistent storage and specialized operations, the backend interacts with a MariaDB Database Layer utilizing the InnoDB storage engine. This ensures transactional integrity via row-level pessimistic locking, structurally managing user profiles, YOLOv8 audit logs, transaction records, and trip histories [13]. For offline manifest caching, the Driver client persists the active trip manifest and walk-in entries to a local on-device store in connectivity dead zones; queued mutations are replayed to the FastAPI synchronization endpoint upon reconnection, where server-side pessimistic locking resolves any capacity conflicts. Finally, the infrastructure seamlessly integrates with external services to extend functionality: the PayMongo API for automated digital fare collection, Firebase Cloud Messaging (FCM) for reliable background push notifications, and the Twilio API to dispatch SMS alerts during SOS emergencies.

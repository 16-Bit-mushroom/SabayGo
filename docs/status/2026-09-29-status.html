AI headcount — the contribution

COMPLETE

Captures no longer need a person to press anything: the system audits a leg automatically when boarding closes and again whenever the van leaves a terminal's geofence, one audit per leg, counted over automatic rows only so a manual spot check cannot satisfy the quota. A variance notifies office, driver and conductor in the same transaction as the audit.

The node never invents a count — an unreachable camera is an error, and writes no row at all.

Live tracking & map

COMPLETE

Both halves of NAHGM now exist: the server map-matches GPS pings to route nodes, and the passenger sees the van, its heading, the travelled trail and per-stop ETAs. The console has a Live Fleet board that chips a silent van. OpenStreetMap tiles via flutter_map — no API key, no billing account, one widget on handset and web.

A trip with no fix yet says tracking begins at departure; a stale fix is labelled last-known, never shown as current.

Van kit stand-in

VERIFIED

Still no physical kit needed: the laptop webcam drives the real audit endpoint and the GPS simulator drives the real tracking endpoint, over the same HTTP APIs the installed kit will use. A phone-camera capture path exists as a manual stand-in until the Orange Pi arrives.

Automatic audits need a camera on the inference host, so alpha vans produce none until the kit is fitted.

Known issues
The single journey-test failure is a fixture self-conflict — the "departs in 20 min" reset needed for check-in has already passed the 6-hour reschedule cutoff. A direct reschedule call returns 200.
Three of the eight "not built" flags in the test report are stale: profile settings, saved destinations and account closure exist, but the script probes the old paths. Change-password is genuinely missing.
Push is polled, not pushed — rows are read every 10–30 s. FCM is schema-ready but not wired, so delivery_status stays queued.
The manuscript names Google Maps, Firebase Auth, FCM push, Twilio and door sensors; the code uses OpenStreetMap, JWT, polling, one of three SMS providers, and the conductor closing boarding. Replacement wording is written.
Automatic capture and the phone capture slot are in-process, so more than one backend worker could double-fire one leg. One for the single-process list in Limitations.
The live map needs internet for OSM tiles; a defence-room demo is well inside OSM's usage policy, heavy automated polling is not.
Passenger avatar fetches an external placeholder image; fails with no network.
Android toolchain (AGP/Kotlin) is a version behind — deferred deliberately.
The data layer still says "seat" where the domain says "space". Nothing a passenger reads does; renaming is a migration, not a UI pass.
